# HillCipher

Реализация шифра Хилла на языке C.

## Зависимости

Для сборки и запуска нужны:

- `gcc`
- `make`

Проверить установку можно командами:

```bash
gcc --version
make --version
```

## Сборка

Собрать проект:

```bash
make
```

После сборки появится исполняемый файл:

```bash
main
```

## Запуск

Запуск стандартного режима:

```bash
make run_standard
```

Запуск рекурсивного режима:

```bash
make run_recursive
```

Также можно запустить напрямую:

```bash
./main standard
./main recursive
```

## Описание файлов

- `main.c` — точка входа в программу. Обрабатывает аргументы запуска и запускает нужный режим работы.
- `matrix.c` — реализация функций для работы с матрицами.
- `matrix.h` — заголовочный файл с объявлениями функций для работы с матрицами.
- `Makefile` — файл для сборки и запуска проекта через `make`.
- `README.md` — описание проекта и инструкция по запуску.
- `LICENSE` — лицензия проекта.
- `standard_encrypt.txt` — результат шифрования в стандартном режиме.
- `standard_decrypt.txt` — результат расшифрования в стандартном режиме.
- `recursive_encrypt.txt` — результат шифрования в рекурсивном режиме.
- `recursive_decrypt.txt` — результат расшифрования в рекурсивном режиме.

## Кратко про шифр Хилла

Шифр Хилла — это блочный полиалфавитный шифр, основанный на линейной алгебре.

Идея алгоритма:

1. Каждая буква текста заменяется числом:
    - `A = 0`
    - `B = 1`
    - ...
    - `Z = 25`

2. Текст разбивается на блоки одинаковой длины.

3. Каждый блок представляется как вектор чисел.

4. Вектор умножается на ключевую матрицу.

5. Все значения берутся по модулю `26`.

Формула шифрования:

```text
C = K * P mod 26
```

где:

- `C` — зашифрованный блок;
- `K` — ключевая матрица;
- `P` — исходный блок текста;
- `mod 26` — взятие остатка по размеру английского алфавита.

Для расшифрования используется обратная матрица к ключевой матрице:

```text
P = K^(-1) * C mod 26
```

Чтобы расшифрование было возможно, ключевая матрица должна быть обратимой по модулю `26`.
